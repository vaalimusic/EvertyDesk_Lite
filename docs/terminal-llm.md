# AI терминал EvertyDesk Lite

Терминал работает как обычная удаленная консоль: вывод идет в моноширинный экран, команды отправляются через строку с prompt `$`, история команд доступна стрелками вверх/вниз. В нижней панели можно попросить LLM разобрать последний вывод и предложить следующую команду.

## Настройки

Откройте `Настройки -> AI терминал`.

- `Включить LLM-помощник в терминале` включает кнопку анализа в окне терминала.
- `Автоматически анализировать вывод после команды` запускает фоновый анализ примерно через секунду после того, как удаленная консоль перестала присылать новый вывод.
- `Провайдер` выбирает backend: `Ollama`, `OpenAI` или `YandexGPT`.
- `Системный prompt` задает поведение помощника. По умолчанию он отвечает кратко, на русском, и предупреждает о рискованных командах.
- `Лимит ответа` и `Temperature` ограничивают длину и вариативность ответа.

## Ollama

Подходит для локальной работы без отправки вывода терминала в облако.

- `Ollama URL`: обычно `http://localhost:11434`.
- `Модель`: имя установленной модели, например `llama3.1`.

Перед использованием убедитесь, что Ollama запущена и модель загружена.

## OpenAI

- `OpenAI endpoint`: по умолчанию используется OpenAI-compatible chat completions endpoint.
- `Модель`: имя модели, которую нужно использовать.
- `API key`: ключ OpenAI. В интерфейсе поле скрыто как пароль.

## YandexGPT

- `Yandex endpoint`: endpoint Foundation Models completion API.
- `API key / IAM`: для API key можно вставить значение без префикса, приложение добавит `Api-Key`. Для IAM token вставьте значение с префиксом `Bearer `.
- `Folder ID`: идентификатор каталога Yandex Cloud.
- `Model URI`: можно оставить шаблон `gpt://{folder_id}/yandexgpt/latest`; `{folder_id}` будет заменен на значение из поля `Folder ID`.

## Как работает анализ

При запросе в LLM отправляется только ограниченный хвост вывода терминала, цель оператора и системный prompt. Команды автоматически не исполняются: ответ можно скопировать или вставить первую найденную команду в строку ввода, после чего оператор сам нажимает ввод.

## Базовые примеры

В окне терминала есть быстрые шаблоны AI-задач:

- `Ошибка`: объяснить последнюю ошибку и предложить безопасную диагностику.
- `Сервис`: проверить состояние службы, логи и план восстановления.
- `Сеть`: проверить DNS, маршрут, доступность хоста и порты.
- `Диск`: найти, что занимает место, без удаления данных.
- `Пакет`: помочь с установкой или обновлением пакета под текущий Linux.

Не включайте облачных провайдеров для сессий, где в терминале могут появиться секреты, токены, персональные данные или коммерческая информация. Для таких случаев используйте локальную Ollama или отключайте AI-помощник.
